the real dashboard App driven only by the labeled fixtures in

Deliberately NOT committed: the generated JS/CSS bundles
(`client/main.js` ≈ 2.0 MB, `client/main.css`, `server/actions.js`).
They are regenerable in one command (see ADOPT-B1.md) and their exact
SHA-256 hashes are recorded in `BUILD-MANIFEST.json` — rerun the
entrypoint and compare hashes to verify reproducibility.

SSR limits: charts render as empty frames (recharts needs a DOM) and
Tailwind utilities are uncompiled in the preview markup; the previews
evidence data flow and view-state, not pixel layout.
